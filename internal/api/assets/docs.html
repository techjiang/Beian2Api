Beian2API文档
首页 OpenAPI 仓库

三分钟上手

下载单个二进制，直接运行，没有任何依赖：

./beian2api serve

默认监听 :8080，数据写在 ./data。打开浏览器就能用网页版查询台。

接口一览

GET/api/v1/query

查询单个域名的备案信息。

参数类型说明
domainstring必填。可带协议与路径，服务端会自动归一化
refreshbool跳过缓存强制回源
curl "http://localhost:8080/api/v1/query?domain=example.com"
{
  "ok": true,
  "data": {
    "domain": "example.com",
    "found": true,
    "records": [{
      "domain": "example.com",
      "unit_name": "示例科技有限公司",
      "unit_type": "企业",
      "site_name": "示例站点",
      "icp_code": "京ICP备12345678号-1",
      "province": "京",
      "audit_time": "2024-01-01",
      "source": "miit",
      "fetched_at": 1735689600
    }],
    "cached": false,
    "stale": false,
    "source": "miit",
    "cost_ms": 312.4,
    "fetched_at": 1735689600
  }
}

字段含义

  • found：公开备案库中是否存在该域名。
  • cached：本次结果来自本地缓存。
  • stale：上游全部不可用，返回的是本地最后快照（此时 notice 会给出说明）。
  • source：实际提供数据的上游名。
POST/api/v1/batch

批量查询，单次最多 50 个域名，服务端内部并发限流。

curl -X POST "http://localhost:8080/api/v1/batch" \
  -H "Content-Type: application/json" \
  -d '{"domains":["qq.com","baidu.com"]}'
GET/api/v1/history

查看某域名的历史快照，并把相邻两次的变化算好给你。

curl "http://localhost:8080/api/v1/history?domain=example.com&limit=10"
GET/api/v1/diff

直接对比最近两次快照，适合做"备案信息被悄悄改了"的检查。

POST/api/v1/watch

把域名加入巡检列表。加入时会先抓一次建立基线，之后每次巡检只在内容真变了才报警。

curl -X POST "http://localhost:8080/api/v1/watch" \
  -H "Content-Type: application/json" -d '{"domain":"example.com"}'
DELETE/api/v1/watch?domain=example.com
GET/api/v1/watch/list
POST/api/v1/watch/run

立即执行一轮巡检，返回本次发现的变更。配置 watch.webhook 后变更会推送到钉钉 / 企业微信 / 飞书 / 任意 HTTP 端点。

GET/api/v1/verify

不查询上游，直接按编码规则校验一个备案号是否成立。可以同时带上 domain 做交叉核对， 用来识别伪造备案号的小作坊网站。

curl "http://localhost:8080/api/v1/verify?code=京ICP备12345678号-1"
{
  "ok": true,
  "data": {
    "input": "京ICP备12345678号-1",
    "valid": true,
    "normalized": "京ICP备12345678号-1",
    "province": "北京市",
    "region": "11",
    "kind": "非经营性备案",
    "serial": "12345678",
    "site_seq": "1",
    "issues": null,
    "fixed": null,
    "cross_check": null
  }
}

它会自动纠正全角字符、多余空格、常见错字（如「泸」→「沪」）和数字段里的字母误写， 纠正过程会在 fixed 里说明。

GET/api/v1/changes

最近记录的备案变更事件，支持 since（Unix 秒）增量拉取。

GET/api/v1/changes.rss

同样的变更事件，输出为 RSS 2.0，可直接喂给 RSS 阅读器或 IM 机器人。

POST/api/v1/admin/backup

服务不停机生成一致性快照到 data/backups/。未配置 API Key 时仅允许本机访问。

运维

备份

数据就是一个文件。数据库有排他文件锁，服务运行时外部进程打不开，所以要备份请走在线接口：

./beian2api backup -server http://127.0.0.1:8080

# 或者
curl -X POST "http://127.0.0.1:8080/api/v1/admin/backup"

服务停着的时候可以直接本地备份：

./beian2api backup -o /path/to/beian2api.db

迁移

把 data/ 目录整个拷到新机器即可。想换存储形态就用 JSON：

./beian2api export -o dump.json   # 旧机
./beian2api import -i dump.json   # 新机

自检

./beian2api doctor

会逐项检查配置、目录可写性、存储状态，并实际打一次上游（被 WAF 拦也会如实告诉你）。

离线演示

不想连外网？在配置里加一个演示数据源，用确定性伪造数据把整条链路跑通：

BEIAN2API_PROVIDERS="mock:1" ./beian2api serve

配置

所有配置都可用环境变量覆盖，也可以用 config.yaml：

环境变量默认说明
BEIAN2API_LISTEN:8080监听地址
BEIAN2API_DATA_DIR./data数据目录
BEIAN2API_API_KEYS空启用鉴权的 key，逗号分隔
BEIAN2API_PROVIDERSmiit:1,apihz:.4数据源与权重，权重 0 即禁用
BEIAN2API_TTL21600缓存秒数
BEIAN2API_WEBHOOK空变更推送地址
Beian2API ← 返回查询台
